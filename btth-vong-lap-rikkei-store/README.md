# Bài tập thực hành Python - Vòng lặp (Rikkei Store)

Tổng hợp 5 bài tập thực hành (BTTH) về vòng lặp trong bối cảnh cửa hàng **Rikkei Store**: tính tiền hóa đơn, thống kê doanh thu, tìm Max/Min, minigame đoán số và kiểm toán doanh thu cuối ngày.

## Danh sách bài tập

| STT | Bài tập | Kiến thức trọng tâm |
|---|---|---|
| 1 | [Tính số tiền hóa đơn cho khách hàng](bai-1-tinh-so-tien-hoa-don/) | `if - else`, toán tử số học (`*`, `//`), tính phần trăm giảm giá |
| 2 | [Thống kê doanh thu cố định trong tuần](bai-2-thong-ke-doanh-thu-tuan/) | `for` + `range()` lặp đúng 7 lần, biến tích lũy, biến đếm, trung bình |
| 3 | [Tìm hóa đơn cao nhất trong ca làm việc](bai-3-tim-hoa-don-cao-nhat/) | Số lần lặp nhập từ bàn phím, thuật toán tìm Max / Min |
| 4 | [Vòng quay may mắn trúng thưởng cho khách VIP](bai-4-vong-quay-may-man/) | Giới hạn lượt bằng `for`, thoát sớm bằng `break`, biến cờ `bool` |
| 5 | [Hệ thống tính toán tổng doanh thu ca liên tục](bai-5-tong-doanh-thu-ca-lien-tuc/) | `while True` + `break`, xử lý thời gian thực, chống chia cho 0 |

Mỗi thư mục bài có `README.md` riêng (đề bài, phân tích, lời giải, kết quả chạy thử) và mã nguồn Python.

## Cách chạy

Yêu cầu Python 3.x. Vào thư mục bài cần chạy, ví dụ:

```bash
cd bai-1-tinh-so-tien-hoa-don
python tinh_hoa_don.py
```
